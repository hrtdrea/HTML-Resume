User Persona Project

This project was based on my Technical Writing class. We needed to create a tutorial for our final. I chose to do one on Canva. Canva is a user-friendly webiste/application that people can start with creating designs and flyers. I had to apply technical writing for websites which need to be accessible for everyone so you have to write it with upmost intention.
